# Projelerim

Kaynak kodu gizli olan projelerimin tanıtımları. Her klasörde projenin ne yaptığını ve nasıl kurulduğunu anlatan bir README var.

| Proje | Ne yapıyor |
|---|---|
| [NodeDine](nodedine) | Restoranlar için QR menü, restoran sayfası ve yönetim paneli (çok kiracılı SaaS) |
| [SigortaTakip](sigortatakip) | Sigorta acentesi için yerel ağda çalışan poliçe programı |
| [LearnStride](learnstride) | FSRS tabanlı İngilizce kelime öğrenme PWA'sı |
| [KVKK Redact](kvkk-redact) | Taranmış PDF'lerde kişisel verileri OCR + LLM ile bulup karalayan araç |
| [Müşteri Bulucu Bot](musteribulucu-bot) | Google Haritalar + WhatsApp + yapay zekâ satış botu |
| [NodeDine WhatsApp Botu](restoran-saas-bot) | Müşteri Bulucu Bot'un n8n ile kurulan ilk sürümü |
| [Asiste](asiste) | WhatsApp üzerinden kişisel planlama asistanı |
| [FinansAI](finansai) | Fiş ve dekonttan harcama kaydeden yapay zekâ destekli finans uygulaması |
| [Yedekleme Servisi](backup-service) | Postgres ve klasörleri şifreleyip Google Drive'a yedekleyen web panelli servis |
| [Köprü](kopru) | Mac ⇄ Windows internetsiz anlık dosya aktarımı |
| [Kod-Mesaj](kod-mesaj) | 6 haneli kodla iki cihaz arasında mesaj ve dosya gönderme |
| [Bütçe Takip](butce-takip) | Kurulumsuz yerel nakit akışı takip programı |
