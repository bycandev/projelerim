# Bütçe Takip

**Gelecek ve ödenecek paraları da hesaba katan, kurulum gerektirmeyen yerel nakit akışı programı.**

> Kaynak kodu gizli. Bu repo projenin ne yaptığını ve nasıl kurulduğunu anlatır.

---

## Ne yapıyor

- Her kayıt üç durumdan birinde: **Var**, **Gelecek**, **Ödenecek**
- Kümülatif bakiye grafiği ayrı panelde, sıfır çizgisine göre artı/eksi gösterimi
- Şifreli giriş
- Veriler bilgisayardaki tek bir SQLite dosyasında

## İlginç kısmı

Python standart kütüphanesi + SQLite. Çift tıkla çalışır, tarayıcıda açılır.

## Teknoloji

Python · SQLite · HTML/JS · Docker
